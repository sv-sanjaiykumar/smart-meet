## Admin account management

Sign in with the starter administrator account (`admin` / `admin123`) to open
the admin dashboard. From there, administrators can create staff and student
logins and browse the saved accounts.

Accounts currently use the app's SharedPreferences-backed local storage. They
are not synchronized between devices and this is not a production server
backend. The starter credentials and locally stored passwords are intended for
development only; replace them and use a secured server-side authentication
service before deploying the app.
